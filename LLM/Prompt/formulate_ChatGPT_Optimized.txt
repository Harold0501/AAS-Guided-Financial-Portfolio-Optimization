--------------------------------------------------
FORMULA CONVENTIONS YOU SHOULD USE
--------------------------------------------------

For each feature, write a formula or precise pseudo-formula that is implementation-ready.

Use clear notation such as:
- i: stock/company index
- t: current feature date
- U_t: set of companies with valid required data at date t
- P_{i,t}: selected price for stock i at date t, usually div_adj_close
- r_{i,t}: stock-level return, usually P_{i,t}/P_{i,t-1} - 1
- R_t: equal-weight portfolio return at date t, usually mean_{i in U_t}(r_{i,t})
- W: backward-looking rolling window length in trading days
- mean_{i in U_t}(...): cross-sectional equal-weight average
- std_{i in U_t}(...): cross-sectional standard deviation
- mean_{s=t-W+1}^{t}(...): rolling time-series average

Rolling-window rules:
- If Version B specifies a window, use that window.
- If Version B is ambiguous but clearly short-term, use 5 or 10 trading days.
- If Version B is ambiguous but clearly monthly/medium-term, use 20 trading days.
- If Version B is ambiguous but clearly quarterly/longer-term, use 60 trading days.
- State the chosen window explicitly in the formula and variables.

Aggregation rules:
- If the feature describes average portfolio behavior, use cross-sectional mean.
- If the feature describes disagreement, concentration, heterogeneity, or dispersion, use cross-sectional standard deviation, interquartile range, entropy, or pairwise correlation, whichever most closely matches Version B.
- If the feature describes co-movement, use pairwise correlation of stock-level return histories within the rolling window.
- If the feature describes breadth, use the fraction of stocks satisfying a condition.
- If the feature describes downside or stress, use downside returns, negative-return fraction, drawdown, volatility, or range-based measures derived only from allowed fields.
